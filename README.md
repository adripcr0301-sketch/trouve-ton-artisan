# Trouve ton artisan

Plateforme web pour la région Auvergne Rhône-Alpes permettant aux particuliers de trouver un artisan et de le contacter.

## Stack technique

- **Frontend** : React.js, Bootstrap, Sass
- **Backend** : Node.js, Express, Sequelize
- **Base de données** : MySQL
- **Maquettes** : Figma

## Structure du projet

```
trouve-ton-artisan/
├── client/          # Frontend React
├── server/          # API Express
├── sql/             # Scripts SQL (création + alimentation BDD)
└── README.md
```

## Prérequis

- Node.js (v18+)
- MySQL (v8+)
- npm
